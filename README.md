# HDB Eco Community · UI 原型

以新加坡 HDB 社区为场景的回合制城市经营 + 政策卡牌游戏的可交互 UI 原型。卡牌部分的界面与交互参照《杀戮尖塔》。

## 在线试玩

**https://hdb-game.vercel.app**

也可以下载 [`prototype/index.html`](prototype/index.html) 后直接用浏览器打开，不需要安装任何东西。

推送到 `main` 后 Vercel 会自动重新部署；根目录的 `vercel.json` 把网站首页指向 `prototype/index.html`。

## 界面布局

- **顶部**：日期与回合时间轴（每回合 1 个月，标出极端高温月份与目标截止回合）、财政、人口 / 容量、实际宜居度、气温
- **左侧**：当前事件（极端高温）与阶段目标
- **中间**：等距视角的既有 HDB 社区，逐栋显示热压力，绿化改造后社区逐渐变绿
- **右侧**：生效中的持续政策、AI 政策顾问
- **底部**：扇形手牌、政治点能量球、抽牌堆 / 弃牌堆 / 已销毁、结束回合按钮

## 操作

| 操作 | 方式 |
|---|---|
| 查看卡牌与关键词说明 | 鼠标悬停在手牌上 |
| 打出无目标的牌 | 拖过虚线后松手（或单击拿起、再单击打出） |
| 打出需要目标的牌 | 拖起后用瞄准箭头指向地图上的组屋 / 空地 / 熟食中心 |
| 取消出牌 | 右键或 Esc |
| 普通建设（花财政，不用卡） | 点击地图上的组屋、空地或停车场 |
| 结束回合 | 点击按钮或按 E |
| 查看牌堆 | 点击左下 / 右下的牌堆 |

## 已实现的设计规则

依据 GDD 主设计线（既有 HDB 生态改造 + 政策卡 + 逐栋高温压力测试）：

- 普通建设走财政，政策卡消耗政治点数
- 极端高温逐栋结算热压力：组屋自身生态改造与公共绿地覆盖分别降低压力
- 组屋生态改造只提升本栋，不增加住房容量，不给邻楼加成
- 事件限定应急卡自动发放、带「保留」，事件结束时未使用则销毁
- 持续政策启动后生成带「保留」的结束牌；事件结束不会自动停止已启动的政策
- AI 顾问把「引擎计算（确定值）」与「AI 判断（建议）」分开显示，不替玩家出牌

> 所有数值均为占位，仅用于演示规则与交互，尚未平衡。
