# HDB · 社区经营

依据绿化之前的城市模拟经营＋政策卡牌构想完成的可玩 v1。沿用 [EVENWaterOne/HDB_GAME](https://github.com/EVENWaterOne/HDB_GAME) 的顶部资源、左侧事件目标、中央低多边形 3D 社区、右侧持续政策/顾问、底部扇形手牌布局。

[在线试玩](https://hdb-city-and-community.rubyfairy2.chatgpt.site) · [完整源码与离线版](prototype/HDB_Game_v1_Source.zip)

## 本体

- **历史模式**：1960–2026，4 章、20 回合，时代开放设施与政策，固定历史节点和社区事件。
- **自由模式**：3 个起始情景，16 / 24 / 36 回合；构筑 10–24 张政策牌，每种最多 3 张；阶段结算后可继续 12 回合。
- 17 类本体建筑：HDB、Condo、熟食中心、商业食阁、商铺、办公、科技办公、平价超市、社区俱乐部、诊所、学校、乐龄中心、图书馆、广场、巴士、地铁、停车场。
- 普通建设使用财政，不消耗政治点；HDB 传统升级增加容量；Condo 只能通过土地招商牌引入，提供即时土地收入、较低持续收入。
- 逐栋人口迁入/流失、空间服务覆盖、维护老化、事件效应、现金流、持续政策及结束牌、普通弃牌/保留/销毁、阶段目标和补救任务。
- 自动存档、3 个手动存档、JSON 导入/导出、本回合撤销、地图图层、城市报告、决策日志与终局评估。

## Green Community DLC

默认关闭。可在历史/自由模式中开启，也可选择独立的 12 回合生态改造挑战。

- 4 类绿色设施：口袋公园、社区花园、雨水花园、公共太阳能设施。
- 单栋和批量生态改造不增加住房容量；公共绿地覆盖独立计算。
- 高温逐栋热压力、居民制冷负担、公共能源开支、能源/碳排模拟指标与暴雨。
- 应急牌自动发放并保留；事件结束时未用的牌销毁。已启动能源补贴继续支出，必须主动使用结束牌。
- 关闭 DLC 时，其设施、牌库、气候事件、目标和能源计算均不进入本体。

## 运行与操作

本项目无需安装依赖。打开 `prototype/index.html` 即可离线运行。Three.js 本地打包，WebGL 不可用时提供可操作的等距 2D 地图。

点击空地建设；点击住宅升级；手牌可以点击拿起、拖动打出。鼠标拖动地图旋转，滚轮缩放，`E` 结束回合，`Esc` 取消，`Ctrl/Cmd+Z` 撤销本回合一步操作。手机竖屏提供政策列表、建造目录、地块选择和报告；横屏保留完整桌面布局。中文 / English 可切换。

## 顾问

默认顾问是明确标注的离线规则分析。设置中可填写兼容 Chat Completions 的完整地址、模型 ID 与可选密钥，启用真实模型问答。密钥只保留于页面会话，不写入存档或浏览器持久存储。接口需支持浏览器 CORS；没有配置接口时仍可完整游玩。模型文本转义显示，不能执行操作或改变数值。

## 检查与文件

```sh
npm run check
npm test
```

`data.js`：设施、政策、时代、事件与数值表；`engine.js`：可在 Node 运行的确定性结算和存档；`view.js`：3D / 2D 地图；`app.js`：完整 UI 与交互；`game.css`：GitHub 布局扩展和手机版。

验证覆盖三种模式的完整流程、目标可达性、DLC 隔离、错误操作不改变状态、空间覆盖、持续政策、应急牌过期、存档恢复与 RNG 一致、手机操作，以及模拟模型回应的文本隔离。不以 DOM smoke harness 代替真实浏览器视觉验收；当前环境没有可用的浏览器 QA 能力，因此 3D 实际显示与拖拽视觉尚需设备试玩。真实外部模型服务未实测。

数值与公式为本次实现参数，尚未完成多人试玩平衡。具体设计依据和补充实现选择见 [实现说明](docs/implementation.md)。
